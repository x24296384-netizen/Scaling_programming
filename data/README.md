# Dataset

Thsis project uses the Web Server Access Logs dataset available on Kaggle:
https://www.kaggle.com/datasets/eliasdabbas/web-server-access-logs

The full dataset is not stored in this GitHub repository because of its size.
After dowloading the dataset, plase the log file inside this `data` folder.
Dataset files are excluded from Git tracking through the `.gitignore` file.
